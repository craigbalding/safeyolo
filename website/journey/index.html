Journey

Start with one contained agent. Grow into a factory.

Most people begin by wanting YOLO mode without the risk. Once agents work unattended, the real question becomes how to get them doing truly useful work. Each stop below is one step on that path, with what you do, what happens and what SafeYOLO guarantees.

  1. Act 1

    Run agents in YOLO mode, safely

    1. 1 · Contain itComing soon

      A sandbox with no network interface, one socket per agent, and your first 428. See the sandbox.

    2. 2 · A home for an agent, not just a box

      Root, tools, browsers, Docker and an API the agent uses to explain its own blocks and ask for more.

  2. Act 2

    Give it real reach

    1. 3 · API access without the secret

      Agents call Slack, GitHub or Docker with a scoped token; the real credential never enters the sandbox.

    2. 4 · Beyond codeComing soon

      Agents that run services and manage remote systems through mediated API calls, and protected media ingestion.

    3. 5 · Approvals that scaleComing soon

      Grants for once, a session or remembered; delegated reviewers; agents proposing exact policy changes. See policy and approvals.

    4. 6 · Work on your host, beltedComing soon

      An agent account on the host confined by a Seatbelt profile, and scoped host writes and ports.

    5. 7 · Commands on remote machines without SSHComing soon

      Signed, bounded operations on Linux, macOS and Windows targets. See remote machines.

  3. Act 3

    See everything

    1. 8 · Evidence and network monitoringComing soon

      Audit, flows, TLS fingerprints, packet capture and investigation warnings. See evidence.

    2. 9 · Threat feeds and signalsComing soon

      Managed policy feeds, NATS signals and guest assessment from adopted signals.

  4. Act 4

    Agents working with agents

    1. 10 · Coord roomsComing soon

      Targeted attention, durable claims and briefs. See Coord.

    2. 11 · Agents that inspect and repair agentsComing soon

      Delegated support, locally or on another SafeYOLO. See other SafeYOLOs.

    3. 12 · Deterministic gatesComing soon

      Checks on admission and acceptance that agents cannot skip. See gates.

    4. 13 · The live software factory

      Three agents ship fixes day and night; none can approve its own work.

  5. Act 5

    Many computers

    1. 14 · FederationComing soon

      Connect instances over NATS, direct a factory on another machine and receive operational notices.
