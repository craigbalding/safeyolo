The audit log

Every decision lands in a canonical JSONL audit log with rotation. It is the integration surface for other tools, and the source an agent reads when it asks the Agent API to explain a block.

Flows, when you want them

Flow recording is opt-in per request. Recorded flows go to a local SQLite store and export as raw requests, curl, HTTPie or HAR.

Below HTTP

Transport metadata is observed by default, without payloads. Packet capture is opt-in and bounded, with PCAP export to a file, pipe or socket. Network security monitoring events describe connections, flows and indicators, including TLS client fingerprints, upstream certificate identity, connection-history changes and a prompt-injection sensor.

What this gives you

  • An answer to "what did the agent try, and why was it allowed?"
  • Evidence another tool can consume
  • Deeper capture only when you turn it on

What it does not do

  • Record every payload by default
  • Capture as much detail inside streamed or passthrough connections
