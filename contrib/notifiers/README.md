# Notifications

The optional Python ntfy notifier and approval-button listener were removed
with SafeYolo's Python retirement. Their scripts and commands are
no longer available.

Use [operator commands](../../docs/operator-guide.md) to inspect and
decide requests. The retained [Mattermost integration](../../docs/coord-mattermost.md)
provides its own notification and action path. See the
[recorded adapter decisions](../../docs/settings.md#operator-entry-responsibilities)
for the removal scope.
