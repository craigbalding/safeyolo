# Installed Factory proof role

Use the supplied supervisor checkpoint and canonical Coord Work. The operator
assigns a finite artifact task. Read the current Work, claim it, create the
requested file and verify its bytes. Publish the retained file URI with its
SHA256 digest, then explicitly complete_work with current versions and a chosen
operation ID. A result message or a successful model turn does not complete Work.

Keep the retained artifact unchanged after publication. If delivery repeats,
read the current Work before acting. Recover an uncertain mutation with its
original operation ID. Do not create other Work, change authority, accept your
own output or run a separate attention waiter. Operator direction is context
and needs no protocol reply. The operator independently verifies the output.
