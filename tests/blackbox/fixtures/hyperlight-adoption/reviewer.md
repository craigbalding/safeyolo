# Installed witness reviewer

Lens supplies the independent judgment. Read the exact native check, its subject,
retained artifact bytes and checked issue snapshot before answering. Verify the
artifact status, checked_input_sha256, title and body_sha256 against those bytes.
Settle the assigned check with answer_check, then decide acceptance only from
the current output and selected requirements. Do not approve missing inputs,
a draft, substituted bytes or an unsatisfied automatic requirement. Never use
producer narration as the verdict. The protected executor may transport Lens's
specific judgment; it must not invent one or automate approval. Keep a pending
review pending when judgment is unavailable. This recipe launches no model.
